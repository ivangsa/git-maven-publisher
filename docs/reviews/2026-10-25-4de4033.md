## Findings

### F1 (minor): `;` is left unencoded, so a servlet-container release repository answers another POM and an unreleased snapshot is deleted

- **What:** D-113 says per-segment encoding through the multi-argument `java.net.URI` constructor makes "any name map to
  exactly one segment of the POM URL". The constructor only quotes characters that are illegal in a path. `;` is legal
  (RFC 3986 sub-delim), so `ReleaseCheck.encode` (`core/src/main/java/io/github/ivangsa/gitpublisher/ReleaseCheck.java:81-97`)
  returns it unchanged. Servlet containers (Tomcat, Jetty: the containers of Nexus and Artifactory, the usual
  release repositories) treat `;...` up to the next `/` as a path parameter and drop it before they map the path. For a
  group directory `acme;rc`, the check asks `/maven2/org/acme;rc/lib/1.0/lib-1.0.pom`. Such a server maps that to
  `/maven2/org/acme/lib/1.0/lib-1.0.pom`, answers 200 with the POM of `org.acme:lib:1.0`, and `org.acme;rc:lib:1.0-SNAPSHOT`
  is dropped even though it was never released. This is the R43 attack again through a different character. (A `;` in the
  artifactId or version also sits in the file segment, so the stripped path loses `.pom` there. The groupId parts are the
  part that can be exploited.)
- **Evidence:** a probe of the same constructor call (`new URI(null, null, "/" + s, null).getRawPath()`) gives
  `1.0;rc -> 1.0;rc`, while `? # % space [ ]` and non-ASCII become `%3F %23 %25 %20 %5B %5D %C3%A9`.
  The new failing review test `core/src/test/java/io/github/ivangsa/gitpublisher/review/R47ReleaseCheckPathParameterReviewTest.java`
  uses a JDK `HttpServer` that applies the container rule (strip `;[^/]*`, then decode).
  Command: `./mvnw -B -q -pl core -am test -Dtest='R47*,R43*,R46*' -Dsurefire.failIfNoSpecifiedTests=false`.
  Result: 3 tests, 1 failure: `[release of org.acme;rc:lib:1.0 (paths as the server mapped them:
  [/maven2/org/acme/lib/1.0/lib-1.0.pom])] Expecting value to be false but was true` (line 68). R43 and R46 pass.
- **Impact:** this can delete data. A `-SNAPSHOT` version that was never released is removed from the branch tip when the
  configured release repository runs on a servlet container. Maven's model validator rejects `;` in a groupId, so this
  tool's own adapters do not publish such a name. But R43's premise is any name Git can hold in the tree, and design §6
  requires the check to ask exactly `<repo>/<groupPath>/<artifactId>/X/<artifactId>-X.pom`.
- **Suggested task:** R47. Quote `;` (as `%3B`) in every segment after the URI constructor, or treat a segment with `;`
  as doubt with no request. Correct D-113's "exactly one segment" claim.

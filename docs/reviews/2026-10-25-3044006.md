### F1 (critical): the committed Windows Maven Wrapper cannot start Maven

- **What:** `mvnw.cmd` determines `$MAVEN_WRAPPER_DISTS` with
  `(Get-Item $MAVEN_M2_PATH).Target[0]`. A normal Windows directory has no `Target` property, so the index
  operation raises `Cannot index into a null array`. `$ErrorActionPreference = "Stop"` aborts the wrapper and it
  prints `Cannot start maven from wrapper` without invoking Maven.
- **Evidence:** from a clean `git archive HEAD` tree, the prescribed native-Windows command
  `./mvnw.cmd --batch-mode --no-transfer-progress -s C:/Users/ivangsa/.codex/maven/settings.xml verify` fails
  before Maven starts with the error above. The same failure occurs in the current committed checkout. The faulty
  expression is at `mvnw.cmd:92`.
- **Impact:** no Maven unit, integration, review, or full-build verification can run on native Windows. T01's
  clean-clone acceptance claim is false.
- **Suggested task:** R41. Correct or regenerate the wrapper so a normal non-link Maven home is supported, then run
  the required full build using the Codex settings file.

### F2 (major): keepVersions can delete a version this publication just deployed

- **What:** `VersionRetention.apply` ranks touched and untouched snapshot directories together by V-level
  `lastUpdated`; Maven stamps that field at session start. A long build that deploys last can therefore rank oldest
  and be deleted before its commit is pushed.
- **Evidence:** committed review test
  `core/src/test/java/io/github/ivangsa/gitpublisher/review/R36KeepVersionsKeepsTheVersionJustPublishedReviewTest.java`
  is constructed precisely with that ordering. The committed algorithm at `VersionRetention.java:66-73` includes
  touched directories in `remaining` and drops the tail.
- **Impact:** the publishing build can report success while its newly deployed version is absent from the branch.
- **Suggested task:** R36 (already open).

### F3 (major): release-aware cleanup is not reachable from either adapter

- **Evidence:** committed review `2026-10-25-250f684.md`, F2 identifies the two adapter call sites; the current

- **Suggested task:** R38 (already open).

### F4 (minor): an HTTPS redirect to HTML is treated as proof that a release POM exists
